# قالبِ فروشگاهِ عمومیِ کوبیتا (`storefront/`)

قالبِ **بی‌نام‌ونشان و عمومیِ** فروشگاهِ اینترنتی که روی **هاستِ خودِ مستأجر** آپلود
می‌شود و از طریقِ API عمومیِ کوبیتا (`/api/shop/*`) به همان حسابِ حسابداری وصل است.

> نقشه‌ی کلی: [`../STOREFRONT_PLAN.md`](../STOREFRONT_PLAN.md). این «قالبِ اول (عمومی)» است؛
> برندِ ipnetcity/دوربینی عمداً در آن نیست — برند/رنگ/نام از تنظیماتِ هر کسب‌وکار می‌آید.

## ساختار
```
storefront/
├── index.html            پوسته (هدر/نویگیشن/فوتر) — بی‌برند، از JS پر می‌شود
└── assets/
    ├── config.js         apiBase + slug + key  ← هنگامِ «ساخت و دانلود» بیک می‌شود
    ├── api.js            کلاینتِ /api/shop/* با هدرهای X-Shop-Slug/Key
    ├── app.js            روتر + خانه/کاتالوگ + محصول + سبد + تسویه→ثبتِ سفارش
    └── style.css         طراحیِ RTLِ روشن، برندپذیر با متغیرِ --brand
```

## استاتیک و بی‌بیلد
هیچ باندلری لازم نیست؛ فایل‌ها را مستقیم روی هر هاست (cPanel/دایرکت‌ادمین/…) می‌گذاری.
داده‌ی زنده (کاتالوگ/قیمت/موجودی/سفارش) سمتِ کلاینت از API می‌آید. سئوی صفحاتِ محصول
با **پیش‌رندرِ زمانِ بیلد** (اینکرمنتِ بعدی: `seo_render` → اسنپ‌شاتِ استاتیک) اضافه می‌شود.

## اتصال به یک حساب
`assets/config.js` را ویرایش کن (یا بگذار خطِ بیلد پُرش کند):
```js
window.SHOP = {
  apiBase: 'https://acc.cubita.ir',   // توسعه: http://localhost:8000
  slug: '<Shop-Slug از پنلِ کوبیتا>',
  key:  '<Publishable Key از پنلِ کوبیتا>',
}
```
سپس در پنلِ «فروشگاهِ کوبیتا» **دامنه‌ی هاست را در «originِ مجاز»** ثبت کن تا API درخواستِ
سایت را بپذیرد (CORS)، و فروشگاه را **منتشر** کن.

## اجرای محلی
هر سرورِ استاتیکی کافی است، مثلاً از داخلِ `storefront/`:
```
python -m http.server 5500
```
سپس `http://localhost:5500` — به شرطِ اینکه بک‌اندِ کوبیتا بالا و یک فروشگاهِ منتشرشده
با همان slug/key موجود باشد.

## نکته‌ها
- **کلیدِ داخلِ config.js «منتشرشدنی» است** (در مرورگر دیده می‌شود)؛ فقط عملیاتِ عمومی را
  مجاز می‌کند. کلیدِ راز/ادمین اینجا نیست.
- **واحدِ نمایشِ قیمت** فعلاً «تومان» است ولی مقدار از حسابداری می‌آید؛ واحد باید با
  تنظیماتِ کسب‌وکار نهایی/تأیید شود (در `app.js` علامت‌گذاری شده).
- **مانده تا MVP:** خطِ بیلد (تولیدِ config + ZIP)، پیش‌رندرِ سئو، و پرداختِ آنلاینِ زرین‌پال
  (درزِ آن در بک‌اند آماده است: `confirm-payment`).
